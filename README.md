# 📊 Sales & Revenue Analysis Dashboard

## 📌 Project Overview

The Sales & Revenue Analysis Dashboard is an interactive business intelligence project developed using Python, Streamlit, Pandas, and Plotly.

The dashboard helps analyze sales performance, revenue, profit, product performance, and regional sales through interactive visualizations and key business metrics.

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Track total revenue and profit.
- Identify top-performing products.
- Compare sales across different regions.
- Analyze category-wise performance.
- Provide interactive filters for better analysis.
- Generate downloadable sales reports.

## 🛠️ Technologies Used

- **Python** – Programming language
- **Streamlit** – Interactive dashboard development
- **Pandas** – Data cleaning and analysis
- **Plotly** – Interactive data visualizations
- **OpenPyXL** – Excel report formatting
- **VS Code** – Development environment

## ✨ Dashboard Features

- Interactive Region, Category, and Product filters
- Date range filtering
- Reset All Filters option
- Total Revenue KPI
- Total Profit KPI
- Total Orders KPI
- Units Sold KPI
- Average Order Value KPI
- Profit Margin KPI
- Monthly Revenue Trend
- Top Performing Products Analysis
- Category Analysis
- Sales Quantity Analysis
- Regional Sales Analysis
- Profit Analysis by Product
- Sales Transaction Details
- CSV Report Download
- Excel Report Download with Summary Sheet

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Sales-Revenue-Dashboard
```

### 3. Install the required libraries

```bash
py -m pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
py -m streamlit run app.py
```

### 5. Open in your browser

```text
http://localhost:8501
```
